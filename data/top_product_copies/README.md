# 상위 제품 광고 문구 데이터

생성 엔진에서 참고하는 제품·문구 자료를 `wrinkle_serum_sample/`에 보관합니다.
수집일은 **2026-10-13**이며, 실시간 가격·순위가 아닙니다.

- `products.csv`: 올리브영 제품 후보 5개, 가격·구성·랭킹·기능성 표시·출처.
- `copies.jsonl`: 공개 페이지에서 발췌한 대표 문구 21개. `judge_level`은 모두 `null`.
- `summary.md`: 문구 유형 분포, 관찰 한계, 동일 본품의 플랫폼 비교 2건.
- `source_register.json`, `evidence/`: 출처와 확인 화면.

## 현재 확인 범위

주름 기능성 유형의 명시적 표시를 확인한 제품은 3개입니다.
온그리디언츠·아이오페는 기능성 고시만 확인되어 유형을 공란으로 남겼습니다.
5개는 스킨케어 랭킹에서 선정한 후보이며, 주름 세럼 전용 TOP5가 아닙니다.
대표 문구 발췌본으로 상세페이지 전체 전수 채록은 완료되지 않았습니다.

## 서비스 연결 시 구분

이 데이터는 시장 표현의 참고 자료이며 자사 효능을 입증하는 자료가 아닙니다.
규정·시험 근거와 별도 보관하고, 타사 수치·시험 조건을 자사 제품에 전용하지 않습니다.
`src/cosmetic_agent/market_reference.py`에서 제품과 문구를 읽어 생성 참고 자료로 전달합니다. 규정 검색용 Qdrant에는 합치지 않습니다.
랭킹·리뷰는 매출이 아니며, 문구의 매출 기여도나 상승률을 계산하지 않습니다.

추가 플랫폼의 제품·문구·출처는 `../market_reference/`에서 함께 읽습니다.
